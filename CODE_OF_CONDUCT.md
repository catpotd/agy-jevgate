# Contributor Covenant Code of Conduct

## Our pledge

We want participation in this project to be free from harassment and other harmful conduct. Contributors should treat each other with respect.

## Expected behavior

- Use welcoming and inclusive language.
- Respect different viewpoints and experiences.
- Accept constructive feedback.
- Focus on what is best for the project and its users.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Sexualized language or unwanted sexual attention.
- Publishing private information without permission.
- Threats, abuse, or deliberate disruption.

## Enforcement

Report conduct that violates this code privately to the maintainers through GitHub. Do not open a public issue with sensitive details. Reports are reviewed in confidence when practical.

Maintainers may remove comments, reject contributions, or restrict participation when necessary to keep the project safe.

## Scope

This code applies in project spaces and when someone represents the project in public spaces.
